# FDE 학습 페이지 구현 계획

사용자가 2026-11-16 제작 시작을 승인했다. 실행 담당은 현재 대화형 Claude Code Opus 5.5 세션이다. Codex는 설계·계획·진행 관리만 맡는다.

## 결정
docs/design.md의 개인 학습 대시보드와 docs/curriculum.md의 보정 커리큘럼을 구현한다. Rust 단일 서버 + HTML/CSS/소량 JS, JSON 콘텐츠, localStorage 진도. AI 기본 경로와 비AI 대체 과제를 제공한다. Rust는 서버 구현 언어이며 학습 실습은 Python 기본이다. 지원 조건 필터는 경력·지역 정보만 비교하며 지원 자격을 보장하지 않는다.

## 순서와 산출물
1. 설치된 ponytail, frontend-design, rust-best-practices를 읽고 공식 문서로 서버 의존성을 확인한다. 최소 Cargo 프로젝트와 localhost 서버를 만든다.
2. 검증 자료에서 12주 콘텐츠·과제·완료 기준·출처를 JSON으로 옮긴다. 자료 상태와 검증일을 함께 표시한다.
3. 오늘의 고객 과제, 주차별 학습, 역량 지도, 종합 프로젝트, 면접, 지원 현황, 근거 자료, 설정·백업 화면을 만든다. 실제 과제 내용을 읽고 수행할 수 있어야 한다.
4. 진도·자기평가·메모·지원 기록·경력/지역/시간 설정을 로컬에 저장한다. 백업 가져오기는 모든 스키마 검증이 성공한 뒤에만 반영한다. 실패 시 기존 데이터를 보존한다.
5. Rust fmt/check/test/clippy를 실행하고 진도 집계·백업 검증·안전한 문자열 출력의 작은 실행 검사를 남긴다. 브라우저에서 375px/1280px, 키보드 이동, 체크 후 새로고침 복원, 백업 왕복과 잘못된 백업을 확인한다.
6. README와 docs/qa.md에 실행 명령, 로컬 주소, 검증 결과와 남은 한계를 기록한다. 서버를 실행해 둔다.

## 실패 시 기대 동작
저장소 접근 실패는 사용자에게 설명하고 현재 화면 데이터를 유지한다. 손상된 진도는 조용히 덮지 않는다. 알 수 없는 백업 버전·자료 ID·잘못된 필드 형식은 가져오기를 거부한다. 메모는 텍스트로 출력한다. 빈 자료와 검색 결과 없음에는 다음 행동을 안내한다.

## 진행 보고
작업 단계가 바뀔 때 대화형 터미널에 현재 작업·완료 파일·다음 검증을 짧게 출력한다. 확인하지 않은 검증을 통과했다고 표시하지 않는다. 공개 배포나 유료 서비스 가입은 하지 않는다.
